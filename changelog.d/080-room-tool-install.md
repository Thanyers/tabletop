- **F080 (D-036, slice 1):** a collaboration space now records the tool package version it runs — `space.installTool` / `space.uninstallTool` through the normal space command path, so the room stores a reference (`packageId`, `version`, `contentHash`, route, title) with who installed it and when, stamped by the domain rather than trusted from the payload. A maker or the manager may install; swapping to a different package must be deliberate (uninstall first) and installing never touches source grants. `CollaborationSpace.tool` is optional, so rooms written before this change still validate.
