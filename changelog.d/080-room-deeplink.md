- **F080 (D-046):** a room keeps its own address. `pathForProjection` always built a `/t/:id` path when a workspace was open, so following a `/s/:id` deep link quietly moved the member to the table screen and the room shell never rendered. The projection now takes a room hint (the app passes it when the open workspace is the room being shown), and a regression test pins `/s/:id` for a room, `/t/:id` for a table.
