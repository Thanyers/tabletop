- **F080 (D-053):** the room can link and unlink its source tables from the page. RoomShell gained a slot for it, the screen maps the joined sources correctly (label, and live/stale versus revoked/missing), and the adapter sends `space.addSource`/`space.leaveSource` through a helper that reads the room's current revision first, so a link is never refused for a stale revision the person could not see. The picker lists the tables from the session, minus the room itself. With this, creating a room, installing a tool and linking tables all work from the UI.
