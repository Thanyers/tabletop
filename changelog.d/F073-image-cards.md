- **แปะรูปบน canvas ได้แบบ post-it (F073, MINOR):** ปุ่ม "Add an image" ข้างปุ่ม post-it รับ JPEG/PNG/WebP · เบราว์เซอร์ย่อด้านยาวสุดเหลือ 1600px ก่อนส่ง · การ์ดรูปลาก ย่อ/ขยาย และใส่คำบรรยายได้ ทุกคนในโต๊ะเห็นสด · ลบได้เฉพาะคนแปะหรือเจ้าของโต๊ะ · ไม่เกิน 20 รูปต่อโต๊ะ (แยกจาก post-it ข้อความ) · server ตรวจชนิดจากเนื้อไฟล์ จำกัด 1.5 MiB และส่งรูปให้เฉพาะสมาชิก · เก็บในตาราง `room_images` ใหม่ของ Room DO (เพิ่มอย่างเดียว ไม่ต้องตั้งค่าก่อน deploy) · รีเซ็ตโต๊ะแล้วรูปถูกลบ · Node guest runtime ยังไม่รองรับ (ปุ่มซ่อน); rollback = revert (ตารางใหม่แค่ไม่ถูกใช้)
