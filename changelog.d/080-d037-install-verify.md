- **F080 (D-037, slice 1):** a room can now carry the package it runs, and the Worker proves it first. `SpaceToolInstallation.definition` is optional and validated on install (the definition must be a valid package naming the same id and version), and `verifyToolInstall` runs in the Room before the command reaches the authority: it hashes `toolPackageContentCanonical` with the same SHA-256 helper the room already uses and refuses a claim that does not match. `toolPackageContentCanonical` was extracted from `toolPackageContentHash` so an async caller can hash the same text. A reference without a definition still installs, which keeps the earlier card-only room working.
