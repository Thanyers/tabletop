- **F080 (D-044, production):** the release pipeline now deploys the assets-only sandbox Worker and redeploys the app with `TOOL_SANDBOX_ORIGIN`, so a release gets the same wiring staging already has. The sandbox Worker name and host are repository variables with defaults (`tabletop-sandbox`, `tabletop-sandbox.ptchrr.workers.dev`), a host that is not a bare name is refused before anything is published as a frame source, and the app keeps `script-src 'self'` because only `frame-src` names the sandbox origin.
