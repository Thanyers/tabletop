- **F080 (D-044):** the tool sandbox can now be served from its own origin, so the app keeps `script-src 'self'`. The Worker publishes a validated `toolSandboxOrigin` in `/api/capabilities` (https only, bare host, no path or query, bounded length; absent or malformed simply omits it and logs one bounded warning), the client parses it the same way, and the room forwards it to the tool host, which uses a cross-origin frame when it is present and the previous srcdoc frame when it is not. Staging now builds and deploys the assets-only sandbox worker and redeploys the app with `TOOL_SANDBOX_ORIGIN`, and the app's `frame-src` lists the two sandbox origins (script-src is unchanged).
