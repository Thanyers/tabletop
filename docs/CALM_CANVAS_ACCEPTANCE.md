# Calm Canvas — ผลตรวจรุ่นปรับการใช้งาน

วันที่ 20 ตุลาคม 2026 · งานตาม [UX audit](UX_AUDIT_2026-10-19_TH.md) และ [แนวทางภาพ](CALM_CANVAS_DESIGN.md)

## สิ่งที่เปลี่ยน

- เอา Use/Arrange ออก ลากหัวการ์ดได้ตลอด ปุ่มย้ายสี่ทิศทางใช้ได้ทั้งเมาส์และคีย์บอร์ด
- รวมทางเปิดเครื่องมือไว้ใน Objects บน Canvas; Connections แสดงเส้นอัตโนมัติเมื่อโต๊ะมีเส้นเชื่อมและจำค่าที่ผู้ใช้เลือก มี Previous view สำหรับกลับจากการเลือกวัตถุ
- ย้ายช่องพิมพ์เข้ามาในโต๊ะ พับประวัติ/รายละเอียดไว้ เปิดแชท กฎ ไฟล์ คน และประวัติจาก Canvas ได้
- เลือกแถวข้อมูลแล้วเลือกคำสั่งได้ทันที เติม record ให้อัตโนมัติ ขอค่าที่ยังขาด และล้างค่าของงานก่อนหน้าเมื่อเปลี่ยน record
- ลดป้ายและคำอธิบายซ้ำ ใช้ชื่อขั้น Preview change → Check rules → Approve rules → Use these rules
- ใช้สีครีม หมึกเข้ม สีประจำหน้าที่ และขอบกระดาษร่วมกันทุกการ์ด สัดส่วนขยายตามงาน ตารางรักษาความกว้างคอลัมน์และเลื่อนแนวนอนได้
- เก็บการยินยอมส่ง AI แยกแต่ละครั้ง เปลี่ยนชุดไฟล์/หลักฐานแล้วต้องยินยอมใหม่ ไม่ลดการตรวจสิทธิ์หรือการอนุมัติกฎ

## เล่นจริงใน local

ทดสอบผ่าน UI โดยตรงใน Brave และ Codex browser ใช้ฐานทดสอบชั่วคราวใหม่ บัญชีจำลองสองคน และ Cloudflare Worker / D1 / Durable Objects จริงในเครื่อง การล็อกอินจำลองและตัวเสิร์ฟ static assets เป็นเครื่องมือทดสอบ ไม่ใช่หลักฐาน Google OAuth หรือ CDN production

| รายการ | ผลที่สังเกตได้ |
|---|---|
| ไฟล์ใหม่ → AI จริง | แนบ `helpdesk-policy.md` ให้ DeepSeek สร้างกฎ 1 collection, 5 actions, 3 tickets; ร่างใช้ 4,914 tokens ใช้เวลา provider 4.819 วินาที |
| ตรวจและเปิดใช้ | อ่าน actions, starting rows และ evidence; Preview / Check / Approve / Use ผ่าน UI, ตรวจโครงสร้าง 5/5; เจ้าของตรวจความตรงนโยบายแยกเอง |
| Helpdesk จบงาน | 14 รายการสำเร็จ ทั้ง 3 tickets เป็น `done`; ครอบคลุม claim, submit, approve, authorize และ reopen แล้วทำซ้ำจนจบ |
| กรณีปฏิเสธ | รับ ticket ที่ยัง blocked ไม่ได้; คนที่ไม่ได้รับงานส่งงานแทนไม่ได้; ช่อง note ว่างไม่ส่งฟอร์ม |
| สองคน | เจ้าของสร้างลิงก์ใช้ครั้งเดียว สมาชิกอีก browser เข้าโต๊ะเดียวกัน เห็นการเปลี่ยนข้อมูลตรงกันและมีเฉพาะคำสั่งตามสิทธิ์ |
| กลับมาทำต่อ | reload ทั้งเจ้าของและสมาชิกแล้วเห็นห้อง กฎ รายการ และประวัติเดิม; รอบนี้ยังไม่พิสูจน์การ restart process ของ local harness |
| แชท AI จริง | สรุปถูกว่าทั้งสาม tickets done โดยไม่เปลี่ยนข้อมูล; provider 1.300 วินาที, 2,704 tokens; ประวัติกลับมาได้หลัง reload |
| ยินยอมตามชุดไฟล์ | ติ๊กยินยอม 1 ไฟล์แล้วแนบไฟล์จำลองที่สอง: เปลี่ยนเป็น 2 ไฟล์ ยกเลิก checkbox และปุ่ม Prepare ถูกปิด ไม่เกิด AI request ใหม่ |
| ย้ายวัตถุ | ลากหัว Tickets แล้วตำแหน่งวัตถุเปลี่ยน แต่มุมมองไม่เปลี่ยน; ปุ่มขวาย้ายอีก 48 หน่วย พร้อมประกาศผล |
| หน้าจอแคบ | ตรวจจริงที่ CSS viewport 481×844; Canvas เหลือพื้นที่เหนือช่องพิมพ์ ตารางเลื่อนแนวนอน จอ 390px อยู่ใน browser regression suite ซึ่งต้องอ่านผล CI เพิ่ม |

เคยเรียก AI สร้างร่างอีกรอบใน harness รุ่นก่อน (5,260 tokens) แล้วหยุดเพราะเครื่องมือ reload assets ของ fixture มีปัญหา เก็บหลักฐานไว้ แต่ไม่นับเป็นการเล่นครบ ไม่มีการเติมคำตอบ AI หรือผลธุรกิจจำลองเพื่อทำให้รอบจริงผ่าน

## เดโมที่รับช่วงเล่นต่อ

| แบบ | Auto | เล่นต่อด้วยมือ |
|---|---|---|
| ตรวจบิล | 15/15 ขั้น; เทียบได้ 2/4 แถว ยอดคาดหมายที่มีหลักฐาน 80 บาท ผลต่าง 10 บาท อีก 2 แถวคง Unknown | พัก/รับช่วง เปิดกฎ สร้างและเปิดใช้ข้อเสนอ; รอบจบ auto รับช่วงแล้ว Save run เพิ่มจาก 1 เป็น 2 รายการ |
| แรงและมวล | 11/11 ขั้น; คำตอบผู้เรียนถูกและผิดถูกแยกไว้ | เปลี่ยนแรง 10 → 20 N มวล 5 kg เวลา 2 s; รถและกราฟเปลี่ยนระยะ 4 → 8 m และบันทึก lesson r2 |
| เกมร่วมมือ | 11/11 ขั้น; โล่ลด hit เหลือ 2 damage, Pip เหลือ 8 HP, Mira ใช้ 1 AP | DM จบตา Goblin แล้วเลือก Mira จบตาด้วยมือ ระบบเดินไป Pip และ reset AP ตามกฎ |

เดโมเหล่านี้ใช้สถานการณ์และภาพที่เตรียมไว้ พร้อม runtime คำนวณจริงในแท็บ ไม่เรียก AI และไม่ใช่เกม D&D ที่รองรับกติกาครบทุกอย่าง

## การตรวจอัตโนมัติและขอบเขต

- PASS: unit / SQL / API 309 tests, Cloudflare integration 65 tests, Component Lab 7 tests
- PASS: typecheck, build, publication pattern scan; token-reference gate ผ่านใน CSS ที่เพิ่ม
- PASS: รีวิวอิสระแบบอ่านอย่างเดียว ไม่พบข้อแก้ไขค้างใน candidate ที่ตรวจ
- เพิ่ม browser regressions สำหรับ Objects, lifecycle, contextual prefill, role filtering, note ไม่ติดข้าม record, แสดงชื่อคน, consent และพื้นที่ mobile; ผล local scripted browser ไม่ถูกนับ PASS เพราะรอบนี้ใช้ CUA เล่นจริง ส่วนผล CI ต้องตรวจจาก PR ของรุ่นนี้
- SKIPPED: automated axe / full contrast audit / screen-reader audit, การทดสอบนิ้วบนโทรศัพท์จริง, invoice เปลี่ยนระหว่างหลักฐานสองชิ้น (fixture มีชิ้นที่เลือกได้เพียงชิ้นเดียว)
- รุ่นนี้ไม่มี schema migration, การเปลี่ยน secrets, สิทธิ์บัญชี หรืองบ AI

รายงานนี้บันทึกผล local ของ candidate; การ deploy staging, บัญชี Google จริง, hosted asset parity และ production เป็น gate แยก ต้องดูผล release ที่ผูกกับ commit เดียวกันก่อนประกาศว่าขึ้นใช้งานแล้ว
