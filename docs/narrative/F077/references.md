## ภาษาภาพของเรา

**สิ่งที่คนควรจำ:** โต๊ะเดิมมีประโยชน์มากขึ้นทีละชิ้น ข้อมูลยังอยู่ กฎที่เลือกแก้ได้ ผลใหม่งอกต่อออกมา

- วัตถุไม่เปลี่ยนชนิด: เก้าอี้ยังเป็นเก้าอี้ ปากกาเพิ่มรอยเขียน ค้อนเพิ่มตะปู; ตัด/เลื่อนกล้องเข้าสู่ canvas โดยไม่แปลงรูปร่างสิ่งของ
- จังหวะเป็นผู้พาไปดู: รอบ3ขยายช่องพิมพ์ให้อ่านคำขอก่อน แล้วพับกลับเมื่อส่งและเน้นสิ่งที่เพิ่มหรือแก้ การ์ดเดิมคงตำแหน่ง
- เส้นเชื่อมมีความหมาย: จากข้อมูลไปวิธีคำนวณ จากวิธีคำนวณไปผล ไม่เป็นเส้นตกแต่งหรือบอก backend capability ที่ยังไม่มี
- หนึ่งจังหวะหนึ่งการเปลี่ยน: เพิ่มการ์ด → พัก; แก้ค่า → พัก; ตรวจข้อเสนอ → กดใช้ → ค่อยเห็นผล
- รักษา contrast กับจังหวะสงบ: กระดาษอุ่น หมึก เขียวมอส และทองเฉพาะจุด ตัวเลขเป็นจุดสนใจเมื่อมีผลเปลี่ยน

## รอบ 3: จากของเพิ่มเอง สู่คำขอที่เปลี่ยนเครื่องมือ

ผู้ใช้ดูรอบ2แล้วไม่เห็นจังหวะเครื่องมือปรับเข้ากับตัวเอง การคงcanvasและเพิ่มวัตถุยังไม่พอ จึงเพิ่มเหตุจากคนและข้อความที่พิมพ์จริงในเรื่อง โดยไม่ต้องหาreferenceใหม่มาแทนปัญหานี้

| รอบ2 | รอบ3 |
| --- | --- |
| คำขอแรกค้าง แล้วการ์ดต่อไปปรากฏเอง | แต่ละความต้องการมีคำขอใหม่ที่พิมพ์ ส่ง ตรวจ และใช้ก่อนเปลี่ยนบอร์ด |
| เปลี่ยนตัวเลขเพื่อแสดงการคำนวณ | ขอปุ่มเพราะกรอกไม่ทัน แล้วกดปุ่มที่ได้ให้เห็นวิธีทำงานเปลี่ยน |
| ตาราง/กราฟ/ส่วนลดเป็นรายการfeature | คนขายค่อย ๆ พบว่าต้องการอะไรระหว่างใช้โต๊ะเดิม |

## รอบ4: เสียงพาเรื่องและภาพเครื่องมือที่ถูกใช้งาน

ทิ้งopeningที่ใช้รูปเก้าอี้/ปากกา/ค้อนเป็นสัญลักษณ์ เปลี่ยนเป็นใบออร์เดอร์ที่ปากกาเขียนรายการจริง และเห็นผลบวกที่ต้องตรวจ/แก้ก่อนเข้าสู่โต๊ะดิจิทัล ภาพและเสียงใช้Englishก่อนตามคำสั่งล่าสุด ไม่มีข้อกำหนด60sอีกต่อไป

เสียง: [edge-tts project](https://github.com/rany2/edge-tts) อธิบายการใช้voice/rateและการบันทึกMP3; รอบนี้เรียกen-US-AriaNeuralเฉพาะบทแต่งเอง เก็บwordtimingไว้จับคู่การกดจริง เอฟเฟกต์เขียนด้วยโค้ด ไม่ดึงเสียงจากreference


## รอบ 5: คืนแนวคิดเครื่องมือที่ปรับให้คน

เสียงและภาพเดินจากปากกา/ค้อน/เก้าอี้ → ปัญหาที่คนต้องปรับงานให้เข้ากับ software → Tabletop → การพิมพ์และใช้เครื่องมือบนโต๊ะเดิม บทอ้างอิงเพิ่มเติมที่ผู้ใช้ให้ใช้เป็นแนวทางเรื่อง timing ตามคำพูด การมีจุดสนใจเดียว และการตรวจภาพก่อน render; ไม่คัดลอก prompt หรือรูปแบบวิดีโอต้นฉบับ

ใช้ภาพถ่ายที่มีสิทธิ์แทนสัญลักษณ์อ่านยาก ดู [รายการภาพและ license](motion/public/objects/SOURCES.md) ภาพคงรูปเดิมและเผยส่วนประกอบตามบท ไม่มี morph; ช่วงท้ายเหลือพื้นขาวกับโลโก้เดิมเท่านั้น
