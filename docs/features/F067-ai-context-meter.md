## ทำไม

ผู้ใช้ไม่รู้ว่าโต๊ะใกล้เต็มเพดานคำขอร่างกฎ (F066: 128 KiB) จนกด Send แล้วเจอ "too large"

## สิ่งที่ผู้ใช้จะเห็น

- ตอนพิมพ์ข้อความที่จะกลายเป็นคำขอแก้กฎ ใต้ช่องแชทมีแถบเล็ก ๆ กับ "AI context 33 / 128 KiB" ที่ขยับตามข้อความ
- เกิน 80% ขึ้น "almost full" สีส้ม · เกิน 100% ขึ้น "too large to send. Remove a file or some rows." สีแดง
- คำถามธรรมดา (ask) ไม่แสดง เพราะใช้เพดานคนละตัว
- ชี้ค้างอธิบายว่านับอะไรบ้าง: ข้อความ, ไฟล์ที่กฎยังไม่อ้าง, กฎ และข้อมูลทุกแถว · ไฟล์ที่กฎอ้างแล้วส่งแค่ชื่อ

## ทำอย่างไร

- `src/tabletop/shared/table-draft-input.ts`: `tableDraftInput(state, prompt)` สร้างส่วนโต๊ะของคำขอ (ย้ายมาจาก `cloudflare/ai.ts`) และ `tableDraftBytes()` วัดเป็น UTF-8 JSON
- Worker และหน้าแชทใช้ฟังก์ชันเดียวกัน ตัวเลขจึงตรงกันเสมอ (มีเทสต์เทียบกับ bytes ที่ provider ได้รับจริง)
- เพดานมาจาก `TABLE_AI_INPUT_BYTES` (F066)
