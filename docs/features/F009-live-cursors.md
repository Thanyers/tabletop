## ทำไม

หลายคนอยู่โต๊ะเดียวกันแต่ไม่รู้ว่าอีกคนกำลังดูหรือชี้ตรงไหน ผู้ใช้อยากเห็นเมาส์ของแต่ละคนพร้อมชื่อแบบ Figma

## สิ่งที่ผู้ใช้จะเห็น

1. ขยับเมาส์บน Canvas → คนอื่นที่เปิดโต๊ะเดียวกันเห็นลูกศรสีประจำตัวพร้อมป้ายชื่อ ณ ตำแหน่งเดียวกันบนโต๊ะ (พิกัดโลกของ Canvas ไม่ขึ้นกับการซูม/เลื่อนของแต่ละเครื่อง)
2. เมาส์ออกนอก Canvas, ปิดแท็บ หรือไม่ขยับ 10 วินาที → ลูกศรหายไป
3. ไม่เห็นลูกศรของตัวเอง · จอสัมผัสไม่ส่งตำแหน่ง

## ขอบเขต

**รวม:** relay ผ่าน WebSocket เดิมทั้ง Worker (Room DO) และ Node · overlay ใน React Flow · throttle · เทสต์
**ไม่รวม:** เก็บตำแหน่งเมาส์ลงฐาน, แสดงว่าใครออนไลน์ใน People, ลากเลือกพร้อมกัน, เมาส์บนหน้าที่ไม่ใช่ Canvas

## โปรโตคอล

- client → server: `{"type":"cursor","x":<number>,"y":<number>}` หรือ `{"type":"cursor","leave":true}` · สูงสุด 128 ไบต์ · key อื่นใด (เช่น `actorId`, `name`) = ปิด socket ด้วย 4400
- server → client อื่นในห้อง: `{"type":"cursor","actorId":"…","x":…,"y":…}` / `…"leave":true` · server ใส่ `actorId` จาก session เอง
- ชื่อที่แสดงมาจาก `view.members` ของผู้รับ ไม่มาจากข้อความ จึงปลอมชื่อไม่ได้ และ actorId ที่ไม่อยู่ในสมาชิกถูกเมิน
- ไม่เขียน storage, ไม่ผ่าน projection/outbox · server ทิ้งเฟรมที่ถี่กว่า 40 ms ต่อ session (client ก็ throttle เท่ากัน)
