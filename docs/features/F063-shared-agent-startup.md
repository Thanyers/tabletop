## ทำไม

ทีมใช้หลาย harness และกลับมาทำงานในแชทหรือ checkout เดิมได้ กติกาที่เพิ่งเข้า `dev` จึงอาจยังไม่อยู่ในบริบทของ agent เดิม อีกทั้ง `CLAUDE.md` เดิมบอกให้อ่าน `AGENTS.md` ด้วยข้อความธรรมดา ซึ่งยังต้องพึ่ง agent เปิดไฟล์เอง

## สิ่งที่ผู้ใช้จะเห็น

Agent ระบุ branch, HEAD และ `origin/dev` ที่ตรวจจริงก่อนเริ่มแก้ ใช้กติกากลางเดียวกัน และส่งงานปกติกลับ `dev` ผ่าน PR โดยแยกจากการ release เว็บ

## ขอบเขต

**รวม:** startup/resume ใน `AGENTS.md`, native import ใน `CLAUDE.md`, คู่มือจุดอ่านและข้อจำกัดของ Codex / Claude Code / OpenCode / DeepSeek Harness

**ไม่รวม:** โค้ดหรือฟีเจอร์ของเว็บ, config ส่วนตัวของสมาชิก, deploy, การอ้างว่าได้ทดสอบ harness บนเครื่องสมาชิกทุกคน

## ข้อเท็จจริงจากโค้ด

ตรวจ 2026-10-23: `AGENTS.md` §4 มีตัวอย่าง fetch แล้วแตก branch จาก `origin/dev` อยู่แล้ว แต่ขั้นเริ่มงานใน §1 ยังไม่มีการตรวจความสดของ dev/กติกาหรือกรณีกลับมาใช้ checkout เดิม; `CLAUDE.md` ยังไม่มี `@AGENTS.md` import
