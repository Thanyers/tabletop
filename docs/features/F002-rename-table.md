## ทำไม

ชื่อโต๊ะตั้งได้แค่ตอนสร้างห้อง พอมีหลายโต๊ะใน My tables จะแยกไม่ออกว่าโต๊ะไหนทำอะไร

## สิ่งที่ผู้ใช้จะเห็น

1. ชื่อโต๊ะอยู่ที่แถบด้านบนของ Canvas
2. **เจ้าของห้อง** กดที่ชื่อแล้วแก้ได้ทันที (Enter บันทึก · Esc ยกเลิก · คลิกนอกช่องบันทึก)
3. สมาชิกคนอื่นเห็นชื่อใหม่แบบสด และเห็นใน My tables ของตัวเอง แต่แก้ไม่ได้

## ขอบเขต

**รวม:** ทุกชนิดห้อง (`table`, `invoice`, `teaching`, `encounter`) · Worker และ Node runtime · My tables / admin metadata แสดงชื่อใหม่

**ไม่รวม:** ไอคอน/สีของโต๊ะ · ประวัติการเปลี่ยนชื่อแยกหน้า

## ข้อเท็จจริงจากโค้ด (2026-10-20)

- ชื่อรับได้ตอนสร้าง: `createSchema` ใน `cloudflare/index.ts` (`title` ≤ 120 ตัวอักษร) แล้วเก็บใน Room DO (`cloudflare/room.ts`)
- ยังไม่มีคำสั่งเปลี่ยนชื่อในทั้ง domain, `server/authority.ts` และ Room DO
- My tables อ่านรายละเอียดผ่าน Room ไม่ได้อ่านชื่อจาก D1 โดยตรง · **ห้องชนิด `table` ใช้ชื่อจากกฎที่เปิดใช้ (`program.title`) ก่อนชื่อห้อง** (`cloudflare/index.ts:67-69`) → ถ้าเปลี่ยนแค่ชื่อห้อง My tables ของโต๊ะที่มีกฎแล้วจะไม่เปลี่ยน
- แถบด้านบนอยู่ใน `src/tabletop/TabletopApp.tsx` (hotspot)

## คำถามเปิด

1. ห้องเดิมที่ไม่มีชื่อ จะแสดงอะไร? (เสนอ: ชื่อชนิดห้อง เช่น "Shared data table" แบบเดิม)
2. ชื่อที่เจ้าของตั้งควร **มาก่อน** ชื่อจากกฎ (`program.title`) ทุกที่ไหม? (เสนอ: ใช่ ชื่อที่ตั้งเองชนะ ถ้าไม่เคยตั้งค่อยใช้ชื่อจากกฎ)
