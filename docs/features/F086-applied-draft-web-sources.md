## ทำไม

ลองค้นเว็บ + อ้างอิงบน staging (2026-10-26, โต๊ะ BMI ตามเกณฑ์ WHO) แล้ว AI ค้นเว็บได้ 6 แหล่งและร่างตารางถูกต้อง แต่โต๊ะไม่มีแหล่งเว็บเลย (`sources: []`, `evidence: []`):

1. ปุ่ม **Add to table sources** อยู่บนการ์ด "ร่างพร้อมให้ตรวจ" เท่านั้น แต่ร่างที่ผ่านการตรวจถูกใช้อัตโนมัติ (F039) การ์ดจึงเป็นแบบ "เพิ่มกฎแล้ว" ที่ไม่มีรายการแหล่งและปุ่ม แล้วถูกนับว่าจบ (`isFinishedResult`) และหายจาก canvas ทันที — ไม่มีทางเพิ่มแหล่งเข้าโต๊ะ
2. (เจอตอนลองใน local) server เพิ่มได้ไม่เกิน 4 แหล่งต่อโต๊ะ แต่ข้อความแจ้งว่า "6 web sources added" และการ์ดจะเสนอ 2 แหล่งที่ใส่ไม่ได้อีกตลอดไป
3. (เจอตอนลองใน local) "แก้กฎ VAT ให้อ้างอิงแหล่งที่ยืนยันแล้ว…" ถูกส่งไปเป็น act/ask แทนร่างกฎ เพราะ "ยืนยัน" ตรงกับวลีสั่งแก้แถว และกติกาของ F082 ต้องมีคำว่าตาราง/คอลัมน์ก่อนจะนับเป็นการแก้กฎ

## สิ่งที่เปลี่ยน

- `webSourcesNotOnTable` (`workspace/table-chat-state.ts`): แหล่งที่ยังไม่อยู่บนโต๊ะ (เทียบ URL แบบที่ server เก็บ, ตัด fragment) และไม่เกินที่ว่าง (`MAX_TABLE_SOURCES` = 4)
- `ui/useTableChat.tsx`: การ์ด "เพิ่มกฎแล้ว" แสดง Sources + ปุ่ม Add to table sources เมื่อยังมีแหล่งที่เพิ่มได้ (และผู้ดูเพิ่มไฟล์ได้) · การ์ดนั้นยังไม่นับว่าจบจนกว่าจะเพิ่มครบ/โต๊ะเต็ม/ผู้ใช้ปิด · ไม่แจ้งเตือน "New rules added" ซ้ำเพราะการ์ดบอกเองแล้ว
- `workspace/command-session.ts`: แจ้งจำนวนที่เพิ่มจริง และบอกว่ากี่แหล่งใส่ไม่ได้เพราะเต็ม 4
- `shared/chat-intent.ts`: ข้อความที่พูดถึงกฎ + ขอแก้/อ้างอิง/หลักฐาน (`อ้างอิง|หลักฐาน|cite|evidence`) และระบุสิ่งที่จะเปลี่ยน → ร่างกฎ · "Change this rule" / "แก้กฎนี้หน่อย" เปล่า ๆ ยังเป็น ask
