## ทำไม

สองคนอยู่โต๊ะเดียวกันแต่เห็นกระดานไม่เท่ากัน: เจ้าของเห็นการ์ด Files ส่วนสมาชิกไม่เห็นเลย (projection ตัด `sources` เป็น `[]`) ผู้ใช้ตั้งใจให้ไฟล์บนโต๊ะเป็นของทุกคนที่ถูกเชิญเป็นค่าเริ่มต้น

## สิ่งที่ผู้ใช้จะเห็น

1. เจ้าของแนบไฟล์ → การ์ด Files ขึ้นบนโต๊ะของทุกคน ตำแหน่งเดียวกัน (shared layout แบบ F007)
2. สมาชิกเปิดการ์ด อ่านชื่อไฟล์และเนื้อหาได้ (Review source text) แต่ไม่มีปุ่มเพิ่ม/ลบ
3. ป้ายบนการ์ดเปลี่ยนเป็น "SHARED TABLE FILES · Everyone at this table can read these files"

## ขอบเขต

**รวม:** projection ส่งไฟล์ให้ participant, runtime แสดง `table.sources` ให้ทุกคน, ตำแหน่งการ์ด Files ใช้ร่วม, ข้อความ consent/UI, เทสต์และเอกสาร
**ไม่รวม:** สมาชิกเพิ่ม/ลบไฟล์, ส่งไฟล์เข้าแชทถาม AI (ยังส่งเฉพาะตอนเจ้าของร่างกฎ), เปิด source quotation/ร่าง/ประวัติร่างให้สมาชิก, ตั้งค่าเปิด-ปิดต่อโต๊ะ

## ข้อเท็จจริงจากโค้ด (2026-10-20)

- `src/tabletop/domain/projections.ts` — จุดกรองเดียวฝั่ง server ทุก view ผ่าน `projectDomain`
- `src/tabletop/runtime/index.ts` — node `table.sources` เคยออกเฉพาะ owner
- `src/tabletop/shared/canvas-layout-ids.ts`, `domain/canvas-layout.ts`, `ui/canvas-layout-scope.ts` — รายการการ์ดที่ใช้ตำแหน่งร่วม
- `cloudflare/table-assistant.ts` ไม่อ่าน `sources` อยู่แล้ว แชทของสมาชิกจึงไม่ส่งไฟล์โดยไม่ต้องแก้

## การตัดสินใจ

| วันที่ | การตัดสินใจ | เหตุผล |
| --- | --- | --- |
| 2026-10-20 | สมาชิกอ่านได้อย่างเดียว เพิ่ม/ลบยังเป็นของเจ้าของ | ผู้ใช้ขอแค่ "ควรเห็น"; เปลี่ยนน้อยที่สุดและไม่เปิดช่องให้สมาชิกลบหลักฐานของกฎ |
