## ทำไม

README ยังอธิบายไม่ชัดว่า Tabletop ทำอะไร ทำไมถึงมี และช่วยแก้ปัญหาอะไร ช่วงหลังแทรกสถานะรุ่น ระบบโฮสต์ และผลทดสอบจนขัดจังหวะเรื่องเล่าของผลิตภัณฑ์

## สิ่งที่ผู้อ่านจะเห็น

ปัญหาของคน → Tabletop และเครื่องมือที่ปรับตามงาน → ตัวอย่างผลลัพธ์ → เริ่มใช้และทำร่วมกัน → ขอบเขตที่ต้องรู้ โดยเก็บน้ำเสียงเดิม

## ขอบเขต

ปรับ README และจัดทางไปเอกสาร acceptance/deployment/user guide ให้รายละเอียดเดิมยังตามได้ ไม่เปลี่ยนโค้ด พฤติกรรม หรือสถานะ deployment
