## ทำไม

ผู้ใช้ลองโต๊ะหารบิลบน staging (2026-10-23) กด "ทำเครื่องหมายว่าโอนแล้ว" เพื่อบอกว่าเพื่อนจ่ายแล้ว แล้ว "ไม่เห็นมันอัปเดตอะไรเลย" สิ่งที่เกิดจริง:

- คำสั่งบันทึกสำเร็จ แต่ไปโดน**แถวของแผนเก่า** (`ฟ้า · s2`) ไม่ใช่แถวของแผนใหม่ (`ฟ้า · record_2_01_…`)
- ช่องเลือกแสดงแค่ค่าฟิลด์แรก + id ภายใน ทำให้ 8 แถวอ่านเป็น "มาย / ฟ้า / ฟ้า / ฟ้า …" แยกไม่ออกว่าโอนให้ใคร เท่าไร แผนไหน
- การ์ดสรุปที่ดูแผนใหม่ไม่เปลี่ยน (เพราะแก้แถวเก่า) และฟอร์มไม่บอกว่าเพิ่งทำอะไรไป

## สิ่งที่ผู้ใช้จะเห็น

- ตัวเลือกในช่อง "Choose a record" อ่านจากค่าของแถวเอง เช่น `ฟ้า · แพร · 2,579.8 · Settled: No · ใหม่` ไม่มี id ภายใน
- แถวที่ค่าเหมือนกันทุกช่องจะต่อท้ายด้วย id ของแถว (มักเป็นชื่ออ่านได้ เช่น `team-south`)
- กดปุ่ม/ฟอร์มสำเร็จแล้ว การ์ดขึ้นบรรทัด `Done: <ชื่อแอ็กชัน> — <แถวที่แก้>` จนกว่าจะเริ่มกรอกใหม่

## ขอบเขต

**รวม:** `ui/record-summary.ts` (ใหม่) · ช่องเลือกแถวใน `GeneratedCanvasObjects.tsx` (controls/form ที่ AI สร้าง) และ `TableCanvasObjects.tsx` (ฟอร์มแอ็กชันของการ์ดข้อมูล) · บรรทัด `Done:` ใน controls
**ไม่รวม:** ซ่อนหรือปิดแถวที่แอ็กชันจะปฏิเสธ (เช่นแถวที่โอนแล้ว) · การทำเครื่องหมายแผนเก่าว่า "ถูกแทนที่"
