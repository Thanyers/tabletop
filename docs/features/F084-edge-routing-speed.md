## ทำไม

โต๊ะหารบิลบน staging (22 การ์ด, 40 เส้น) ทำให้ Chrome ค้างทั้งแท็บตอนเปิด (2026-10-26) — Long Animation Frame วัดได้เฟรมเดียว 30 วินาที: React render 19.6 วิ + ResizeObserver ของ React Flow (`updateNodeInternals`) 10.7 วิ ทั้งสองส่วนคือ `routeConnections` ที่ถูกเรียกใน `useMemo` ของเส้นเชื่อมทุกครั้งที่การ์ดถูกวัดขนาด

รันซ้ำใน Node ด้วย layout จริงของโต๊ะนั้น: 40 เส้นใช้ **8.7 วิ** ต่อรอบ (grid 295×301 จุด, ค้นหา 4 ครั้งต่อเส้น, เฉลี่ย 110k state ต่อครั้ง) · profile: `shortestPaths` 42%, `laneCost` 28%, heap 23%

## สิ่งที่เปลี่ยน (`shared/edge-routing.ts`)

1. **lane cost ต่อ grid edge แบบสะสม** — เดิมทุกก้าวของการค้นหาไล่ interval ของเส้นก่อนหน้าทั้งหมด ตอนนี้บวกครั้งเดียวตอนวางเส้น (ลำดับการบวกเดิม ค่าเท่าเดิม)
2. **A\* แทน Dijkstra** — ประมาณระยะ Manhattan ไปยังปลายทางที่ใกล้สุด ซึ่งไม่เกินต้นทุนจริงเสมอ (ทุกก้าวแพงอย่างน้อยเท่าความยาว) จึงยังได้เส้นที่ถูกที่สุด
3. **หยุดเมื่อไม่มีทางชนะ** — เมื่อต้นทุนต่ำสุดที่เหลือในคิวแพงกว่าเส้นที่ดีที่สุดที่เจอแล้ว (จากด้านนี้หรือด้านก่อน) ก็หยุด เพราะ `routeOne` เปลี่ยนเส้นเฉพาะเมื่อถูกกว่าแบบเคร่งครัด
4. ใช้ buffer ของการค้นหาซ้ำต่อ grid แทนสร้าง array ใหม่ทุกครั้ง
