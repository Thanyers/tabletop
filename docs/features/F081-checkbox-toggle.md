## ทำไม

ผู้ใช้ให้ AI ทำ todo list บนโต๊ะหารบิล (staging, 2026-10-26) แล้วอยากให้ "เสร็จ/ไม่เสร็จ" เป็น checkbox · ตอนนั้นช่องใช่/ไม่แสดงเป็นข้อความ `Yes`/`No` ต้องเลือกงานในฟอร์มแล้วกดปุ่ม และ AI สร้างแค่ "ทำเครื่องหมายว่าเสร็จแล้ว" ไม่มีทางเอาติ๊กออก

## สิ่งที่ผู้ใช้จะเห็น

- ในการ์ดตาราง ช่องใช่/ไม่เป็น checkbox · ติ๊กแล้วรันกฎที่ตั้งค่าช่องนั้นให้แถวนั้น
- การ์ดตารางตอนย่อเป็น **checklist** (ติ๊ก + ข้อความของแถว, งานที่เสร็จขีดฆ่า, สูงสุด 8 แถว) เมื่อช่องใช่/ไม่นั้นติ๊กได้ทั้งสองทาง
- ไม่มีกฎที่ทำได้ → checkbox กดไม่ได้ ชี้แล้วขึ้นวิธีขอ AI เพิ่ม
- AI สร้างกฎ `toggle` ได้: กฎเดียวทั้งติ๊กและเอาติ๊กออก

## ขอบเขต

**รวม:** effect `{record, field, op: "toggle"}` (domain, schema, validation, id-normalization, คำอธิบายกฎ, schema guide) · `ui/checkbox-actions.ts` · checkbox ใน `TableCollectionView` (`TableCanvasObjects.tsx`) ทั้งตารางขยายและ checklist ตอนย่อ
**ไม่รวม:** การ์ดชนิด "Checklist" แยกใน DSL (ข้อ 3 ของข้อเสนอ) · ช่องพิมพ์เพิ่มงานท้าย checklist

## การตัดสินใจ

| วันที่ | การตัดสินใจ | เหตุผล |
| --- | --- | --- |
| 2026-10-26 | `toggle` ไม่มี `value` (schema เป็น union) | ไม่มีค่าที่มีความหมายให้ใส่ · AI ไม่ต้องเดา |
| 2026-10-26 | checkbox เลือกกฎที่รับแถวนั้นเป็น input เดียว ไม่ใช้กฎที่ต้องรอตา · ถ้ามีทั้ง toggle และ set ใช้ toggle | กดแล้วทำงานทันทีโดยไม่ต้องกรอกอะไรเพิ่ม |
| 2026-10-26 | การ์ดย่อเป็น checklist เฉพาะช่องที่ติ๊กได้สองทาง | ช่องอย่าง "Available" ของอุปกรณ์เปลี่ยนผ่านกฎยืม/คืนที่มีเงื่อนไข ไม่ใช่ todo · เทสต์เดิมของการ์ดอุปกรณ์ยังตรง |
