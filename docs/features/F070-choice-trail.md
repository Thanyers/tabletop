## ทำไม

ผู้ใช้ลองโต๊ะหารบิลเมื่อ 2026-10-23 แล้วบอกว่า "ทำอะไรก็ผิดง่าย แก้แล้วสับสน" จุดที่เห็นชัด:

- คำตอบ AI มีชิปตัวเลือกให้กด (เช่น "เสนอสร้างชุดปุ่มสร้างแผนโอนใหม่") แต่กดแล้ว**ชิปหน้าตาเหมือนเดิม** ไม่รู้ว่าเลือกอันไหนไปแล้ว และกดซ้ำได้จนเกิดการ์ดซ้ำ
- การ์ดคำตอบใหม่ที่เกิดจากชิป**ไม่บอกว่ามาจากคำถามไหน** การ์ดใหม่ไปต่อแถวด้านบน การ์ดเก่าถูกดันลง ลองหลายตัวเลือกแล้วจับคู่ไม่ได้ว่าอันไหนตอบอะไร

## สิ่งที่ผู้ใช้จะเห็น

1. กดชิปตัวเลือกใต้คำตอบ AI → ชิปนั้นเปลี่ยนเป็นสถานะ "เลือกแล้ว" (สีต่าง + เครื่องหมายถูก) ทันที
2. การ์ดคำตอบใหม่ (ขั้นถัดไป) ไปวางทางขวาของการ์ดคำถาม และมีเส้นลากจากการ์ดคำถามไปหา พร้อมป้ายบนเส้นเป็นข้อความตัวเลือกที่เลือก
3. เลือกอีกตัวเลือกจากการ์ดเดิม → ได้อีกกิ่ง วางเรียงลงมาทางขวา เห็นเป็นต้นไม้ของการตัดสินใจ
4. กดชิปที่เลือกแล้วอีกครั้ง → ไม่ส่งซ้ำ แต่พาไปที่การ์ดขั้นถัดไปของตัวเลือกนั้น
5. การ์ดขั้นถัดไปถามต่อและเลือกต่อได้ เส้นจะต่อเป็นทอด ๆ

## ขอบเขต

**รวม:** ชิป `suggestions` ของคำตอบชนิด `explanation`/`clarification` (`ChatCardContent` ใน `useTableChat.tsx`) · บันทึกว่าการ์ดไหนเกิดจากการ์ด/ตัวเลือกไหน · เส้นบน canvas ระหว่างการ์ดแชท · ตำแหน่งการ์ดขั้นถัดไป

**ไม่รวม (v1):**
- ไม่เก็บบน server: ข้อมูลอยู่ใน localStorage ของคนที่กด (key เดิม `tabletop:r1:private-chat:<scope>`) สมาชิกคนอื่นและเครื่องอื่นจะไม่เห็นเส้น/สถานะเลือกแล้ว
- ไม่รวมตัวเลือกของร่างกฎ (`ClarificationAnswers`) และปุ่ม `Prepare changes`
- ไม่เปลี่ยน contract ของ assistant (ตัวเลือกยังเป็นข้อความ ไม่มี id)

## ข้อเท็จจริงจากโค้ด (ตรวจ 2026-10-23 บน `origin/dev` 2f741d7)

- ชิปอยู่ที่ `ChatCardContent` (`src/tabletop/ui/useTableChat.tsx`) กดแล้วเรียก `send(followUpPrompt(card.prompt, option))` ซึ่งสร้าง `ChatCard` ใหม่ id `answer-<uuid>` ไว้หน้าสุดของรายการ
- `ChatCard` (`table-chat-state.ts`) ไม่มี parent/option · contract `table-assistant-contracts.ts` ตัวเลือกเป็น `string[]` สูงสุด 4 ตัว
- localStorage ส่วนตัวเก็บ `{dismissed, cardIdsByJob}` · `cardIdsByJob` ทำให้ card id คงเดิมหลัง reload → ใช้ card id เป็นตัวอ้างอิงได้
- ตำแหน่งการ์ดแชทตั้งเป็น `{x: 760, y: 40 + index*300}` · `CanvasWorkspace` ใช้ layout ที่เก็บไว้ก่อน แล้วค่อย `object.position`
- เส้นบน canvas สร้างใน `CanvasWorkspace` (`connections` → `routeConnections` → edge `canvasConnection`) จาก `plan.bindings` เท่านั้น การ์ดแชทไม่เคยเป็นปลายเส้น · ป้ายบนเส้นมาจาก `RoutingLink.label`
- สวิตช์แสดงเส้น (`display.connections`) ซ่อนเส้นทั้งหมด รวมถึงเส้นใหม่นี้
