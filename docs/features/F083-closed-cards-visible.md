## ทำไม

ผู้ใช้เปิดโต๊ะหารบิลบน staging (2026-10-26) แล้วเห็นว่า "ข้อมูลหาย" ทั้งที่ข้อมูลบน server ครบ (ใบเสร็จ 23 / รายการโอน 8 / งาน 6) — การ์ด 7 ใบ (ใบเสร็จ สมาชิก รายการโอน สิ่งที่ต้องทำ สรุปงานรายคน Rules Actions) ถูกซ่อนไว้ในเบราว์เซอร์นั้น และไม่มีอะไรบน canvas บอกว่าซ่อนอยู่ สาเหตุมีสามข้อ:

1. **การ์ดที่ AI เพิ่งสร้างตามคำขอถูกซ่อนทันที** — กฎ "เปิดดูครั้งแรก" (`startsClosed`) ปิดตาราง/Rules/Actions ทุกครั้งที่ id ใหม่โผล่ ไม่ใช่แค่ครั้งแรกที่เปิดโต๊ะ
2. **ไม่มีอะไรบอกว่ามีการ์ดถูกซ่อน** — ต้องไปเปิดแผง Objects หรือคลิกขวาที่ canvas เอง
3. **แท็บเก่าเขียนชุดซ่อนทับ** — แต่ละแท็บถือสำเนาของตัวเองแล้วเขียนทั้งชุดลง localStorage แท็บที่ค้างหรือเปิดค้างไว้จึงซ่อนการ์ดที่อีกแท็บเพิ่งเปิดกลับไป

และผู้ใช้แจ้งเพิ่มว่า dropdown (เช่น "Choose an action…") เพี้ยนตลอด: ลูกศรไปติดท้ายข้อความแทนที่จะอยู่ขอบขวา

## สิ่งที่เปลี่ยน

- `cardsClosedOnFirstLook` (`ui/canvas-view-state.ts`): ปิดตาราง/Rules/Actions/คน/ประวัติ เฉพาะตอนเบราว์เซอร์นี้เห็นโต๊ะครั้งแรก (ยังไม่มี seen) · การ์ดที่โผล่ทีหลังเปิดไว้
- `changeHidden` + `isHiddenKey`: เปิด/ปิดการ์ดโดยอ่านค่าล่าสุดจาก storage ก่อนแก้ทีละ id · ทุกแท็บฟัง `storage` event แล้วตามค่าเดียวกัน
- ป้ายบน canvas ข้างปุ่ม Objects: "N closed cards · Show all" (hover เห็นชื่อการ์ด) กดแล้วเปิดการ์ดตารางทั้งหมด (การ์ดคน/ประวัติยังปิด) · ไม่แสดงตอนแผง Objects เปิดอยู่
- `tabletop.css`: select แบบ `appearance: base-select` จัดกลางแนวตั้ง มีช่องห่าง 8px และลูกศรชิดขอบขวา (`margin-inline-start: auto`)

## ผลตรวจ

- local (`wrangler dev`, โต๊ะทดสอบที่มีการ์ดสรุป 1 ใบ):
  - ล้าง seen/hidden แล้วเปิดใหม่ → เห็นแค่การ์ดสรุป + ป้าย "3 closed cards · Show all" (Rules · สิ่งที่ต้องทำ · Actions)
  - กด Show all → การ์ดขึ้นครบ 4 ใบ ป้ายหาย · storage เหลือแค่ people/history
  - เพิ่มตาราง "บันทึกทริป" ผ่าน `evolve.propose` + `autoApply` → การ์ดใหม่ขึ้นทันที ไม่ถูกซ่อน
  - สองแท็บ: แท็บ A ซ่อนงาน → แท็บ B ตามทันที (ป้าย 1 closed card) · A เปิดงานกลับ แล้ว B ซ่อน Actions → storage มีแค่ Actions งานไม่ถูกซ่อนกลับ
  - dropdown ในการ์ด Actions: ข้อความอยู่กลาง ลูกศรชิดขวา
