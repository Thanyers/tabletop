## ทำไม

สองคนเปิดโต๊ะเดียวกันแล้วเห็นการ์ดคนละตำแหน่ง เพราะตำแหน่งส่วนใหญ่จำไว้ใน localStorage ของแต่ละเบราว์เซอร์ และการ์ดที่ยังไม่มีใครลาก แต่ละเครื่องจัดวางเองตามขนาดจอ

## สิ่งที่ผู้ใช้จะเห็น

- การ์ดที่ทุกคนเห็น (Rules, Actions, ตาราง, มุมมองที่ AI สร้าง, People, History) อยู่ตำแหน่งเดียวกันทุกเครื่อง และย้ายตามกันแบบสด
- เปิดโต๊ะครั้งแรก ผังที่จัดวางอัตโนมัติถูกบันทึกให้ทุกคนเริ่มจากผังเดียวกัน
- สองคนลากคนละการ์ดพร้อมกัน ไม่เด้งกลับและไม่ขึ้นข้อความเตือน

## ขอบเขต

**รวม:** การ์ดที่ทุกคนเห็น · ตำแหน่งเริ่มต้น · ลองส่งใหม่เมื่อชนกับการย้ายการ์ดใบอื่น

**ไม่รวม:** การ์ด Files (ไฟล์ส่วนตัวของเจ้าของ) · การ์ดคำตอบแชท (เห็นเฉพาะผู้ถาม) · มุมมอง/การซูม (viewport) ยังเป็นของแต่ละเครื่อง · การ์ดขยับระหว่างลาก (ส่งเมื่อปล่อย)
