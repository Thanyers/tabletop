## ทำไม

ผู้ใช้แจ้ง (2026-10-26, มี screenshot) ว่าตรงช่องแชทมีพื้นหลังบังบอร์ด การ์ดถูกตัดเป็นเส้นตรงเหนือช่องแชท · สาเหตุ: `.tt-canvas-panel--composer { padding-bottom: 96px }` (มือถือ 90px) ทำให้ canvas หยุดเหนือช่องแชท เหลือแถบสีพื้นเปล่า ๆ ทั้งแถว

## สิ่งที่เปลี่ยน (`ui/calm-workspace.css`)

- `padding-bottom: 0` — บอร์ดวิ่งต่อใต้ช่องแชท ช่องแชท (`position: absolute`) ลอยอยู่บนบอร์ดเหมือน island
- มือถือ: ช่องแชทกว้างเต็มจอจะทับปุ่มซูม จึงยกปุ่มซูมขึ้น 76px

## ผลตรวจ

- local Chrome: ใต้ช่องแชทเป็นบอร์ด (ลายจุด) ต่อเนื่อง ไม่มีแถบพื้นหลัง
