## ทำไม

ผู้ใช้แจ้ง (2026-10-26) ว่าเอาเมาส์ไว้บนการ์ดแล้ว scroll เพื่อเลื่อนดูข้อมูล บอร์ดกลับซูม · React Flow ซูมทุก wheel event ยกเว้นเป้าหมายอยู่ในองค์ประกอบที่มี class `nowheel` · เดิม `CanvasNodeBody` ใส่ `nowheel` เฉพาะเมื่อ **ตัว body ของการ์ด** ล้น แต่การ์ดตารางที่ขยายแล้ว (body ไม่ล้น) มีพื้นที่เลื่อนข้างใน เช่น `.tt-table-grid-scroll` (สูงสุด 370px) จึงซูมแทนเลื่อน

## สิ่งที่เปลี่ยน (`ui/CanvasWorkspace.tsx`)

- `CanvasNodeBody` ฟัง `wheel` แบบ native บน body การ์ด: ถ้ามีพื้นที่เลื่อนตั้งแต่ใต้เมาส์ขึ้นมาถึง body ที่ยังเลื่อนไปทางนั้นได้ (`canScrollWithin`) จะหยุด event ไม่ให้ถึงตัวซูมของ React Flow · เลื่อนสุดแล้ว หรือกด Ctrl/⌘ (pinch) บอร์ดยังซูมได้ตามเดิม
- กติกาเดิม (`nowheel` เมื่อ body ล้น) คงไว้

## ผลตรวจ (local Chrome, scroll จริง)

- การ์ด "สิ่งที่ต้องทำ" ขยาย ตารางข้างในล้น: scroll ลง 2 ครั้ง → ตารางเลื่อน 0 → 200 · ลงต่อจนสุด 261 · ขึ้น 2 ครั้ง → 61 · ระหว่างนั้นบอร์ดซูมคงที่ 1.15
- scroll บนพื้นที่ว่างของบอร์ด → ซูม 1.15 → 0.87 (ยังใช้ได้)
